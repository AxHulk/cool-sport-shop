## Проблема

Сейчас в `src/pages/Checkout.tsx` редирект на платёжную форму Т-Кассы выполняется **только** если выбран метод `dolyami` (строка 179: `if (form.paymentMethod === 'dolyami')`). Для `card` и `sbp` код просто пропускает вызов `tinkoff-init`, чистит корзину и показывает экран «Спасибо за заказ» — никакой оплаты не происходит.

## Что сделаю

1. **`src/pages/Checkout.tsx`** — убрать условие `if (paymentMethod === 'dolyami')`. Для любого из трёх методов (`card` / `sbp` / `dolyami`) вызывать `tinkoff-init` и редиректить на `payment_url`. Передавать выбранный `payment_method` в тело запроса.

2. **`supabase/functions/tinkoff-init/index.ts`** — расширить подсказку метода на форме Т-Кассы:
   - `dolyami` → `DATA.PaymentMethod = "dolyame"` (как сейчас)
   - `sbp` → `DATA.PaymentMethod = "sbp"` (СБП откроется сразу с QR без шага выбора)
   - `card` → ничего не передаём, Т-Касса покажет форму карты по умолчанию

3. **Экран «Спасибо»** оставить — он будет показываться после возврата с Т-Банка (`?payment=success` от webhook'a / кнопки «В магазин»), как и для Долями сейчас.

## Что нужно проверить после

- Заказ картой → редирект на форму Т-Кассы → ввод тестовой карты `4300 0000 0000 0777` (12/30, 111) → финальный экран Т-Банка «Оплачено».
- Заказ СБП → редирект на форму Т-Кассы → сразу QR-код СБП.
- В админке статус заказа меняется на `paid` после webhook `CONFIRMED`.

## Важно (на стороне Т-Банка)

В кабинете Т-Кассы → Магазины → терминал → **Способы оплаты** должны быть включены: «Банковская карта», «СБП». Если СБП не подключен, при выборе СБП Т-Касса отдаст ошибку — тогда оставим только карту/Долями до подключения.
