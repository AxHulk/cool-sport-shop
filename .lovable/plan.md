## Проблема

`object-cover` обрезает фото (плечи/ноги модели), `object-contain` показывает серые полосы по бокам исходника. Нужно показать фото целиком, но без некрасивых краёв.

## Решение

Использовать приём премиальных e-commerce галерей (Zara, COS, Aritzia): то же самое фото ставится фоном с сильным размытием и лёгким затемнением, а сверху — оригинальное фото с `object-contain`. Края визуально «растворяются» в собственных цветах кадра, фото не обрезается, выглядит дорого и кинематографично.

### Что меняется

Файл: `src/components/ProductImageSpin.tsx`

```text
┌─────────────────────────────┐
│ blurred(current image)      │  ← absolute inset-0, scale-110, blur-2xl, brightness-95
│   ┌───────────────────┐     │
│   │                   │     │
│   │   sharp image     │     │  ← object-contain, relative z-10
│   │   (contain)       │     │
│   │                   │     │
│   └───────────────────┘     │
└─────────────────────────────┘
```

Конкретно:
- Контейнер: убрать `bg-muted`, оставить `overflow-hidden`.
- Добавить `<img>`-фон: тот же `images[currentFrame]`, `absolute inset-0 w-full h-full object-cover scale-110 blur-2xl brightness-95`, `aria-hidden`.
- Основное `<img>` оставить с `object-contain`, добавить `relative z-10`. Зум/пан применяются только к нему.
- Стрелки, точки, кнопки зума уже `z-10` — поднять до `z-20`, чтобы быть над фоном.

### Запасной вариант (если не понравится)

Заменить размытый фон на сплошной кремовый `bg-[hsl(var(--secondary))]` или белый — фото не режется, края просто становятся одного спокойного тона вместо серого. Менее эффектно, но максимально чисто.

### Альтернативы, которые я отбросил

- Кропать исходники в Photoshop/скриптом — медленно, и поломает уже выложенные фото в других местах.
- `object-cover` с разной точкой фокуса — всё равно режет.
- Прозрачный PNG — у нас JPG с серым студийным фоном, перегенерировать через AI рискованно для уже одобренных фото.

## Проверка после внедрения

Открыть `/product/12-ivory` на desktop и mobile, пролистать все 6 кадров — убедиться, что модель не обрезана и серые полосы исчезли в размытом фоне того же цвета.
