# Исправить «Бронь» на складе

## Как сейчас
- При каждом оформлении заказа (даже неоплаченного) товар добавляется в «Бронь».
- Бронь никогда не снимается: ни после оплаты, ни после отказа банка, ни после истечения срока.
- «Доступно» = Остаток − Бронь, поэтому сайт прячет товар, хотя он реально есть. Например, сумка Айвори: остаток 4, бронь 7 — на сайте её нельзя купить.

## Как будет
1. **Бронь держится только пока клиент платит.** Заказ создан → товар в брони.
2. **Оплата подтверждена банком** → бронь снимается, а остаток уменьшается сам (не нужно списывать вручную).
3. **Оплата отклонена или истекла** → бронь снимается, товар снова доступен.
4. **Бронь старше 1 часа без оплаты** снимается автоматически при ежечасной проверке банка.
5. **Сейчас:** обнулить всю накопленную бронь — она вся «зависшая» от старых заказов; ваши остатки останутся как вы их проставили.
6. **В админке:** кнопка «Сбросить бронь» у каждой позиции и подсказка, что значит столбец.

## Технически
- Добавить в `orders` поле `stock_state` (`reserved` / `deducted` / `released`), чтобы не списать/снять дважды.
- Общий helper в `_shared` для `tinkoff-webhook` и `tinkoff-check`: при `CONFIRMED` — `quantity -= q, reserved -= q`; при `REJECTED/AUTH_FAIL/DEADLINE_EXPIRED/CANCELED` — `reserved -= q`.
- `tinkoff-check` (cron) снимает бронь у неоплаченных заказов старше 1 часа.
- `admin-api`: действие `resetReserved`; `AdminInventory.tsx` — кнопка и подсказка.
- Разово: `UPDATE products_inventory SET reserved = 0`.
