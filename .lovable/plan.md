

## Что меняется

Каталог переделываем под минималистичный стиль референса (planta-rosa). Убираем боковую панель фильтров и переключатель цветов — каждый цвет становится отдельной карточкой. На карточке появляется "hover-scrubber": ведёшь мышью слева направо — переключаются изображения товара, под фото (или над ним) — тонкие риски-индикаторы, показывающие текущий кадр.

## Новый вид страницы каталога

```text
┌────────────────────────────────────────────────────────────┐
│ Главная / Каталог                                          │
│                                                            │
│ Каталог                                                    │
│                                                            │
│ [Все] [Леггинсы] [Топы] [Майки] [Рашгарды] [Сумки] [Лонг.] │
│                                              По популярн ▾ │
│                                                            │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐        │
│ │  ▬ ▬ ▬   │ │  ▬ ▬     │ │  ▬ ▬ ▬   │ │  ▬ ▬     │        │
│ │          │ │          │ │          │ │          │        │
│ │   IMG    │ │   IMG    │ │   IMG    │ │   IMG    │        │
│ │          │ │          │ │          │ │          │        │
│ │          │ │          │ │          │ │       ♡  │        │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘        │
│  Леггинсы     Топ          Рашгард      Сумка              │
│  6 500 ₽      5 500 ₽      7 600 ₽      6 900 ₽            │
└────────────────────────────────────────────────────────────┘
```

- Сетка: 2 колонки на мобиле, 3 на планшете, **4 на десктопе** (как у референса — крупнее и просторнее).
- Карточка: фото на белом фоне, под фото — название мелкими капсами и цена жирным.
- Риски-индикаторы — над фото сверху карточки, по числу изображений. Активная — тёмная и длиннее, остальные — серые тонкие.
- Сердечко избранного — поверх правого верхнего угла фото, без фона-плашки.
- Нет: блока цветовых кружков, кнопки «В корзину» при наведении (карточка ведёт на страницу товара — там и добавляют), бокового списка фильтров.

## Hover-scrubber механика

- Карточка делится мысленно по горизонтали на N равных зон (N = количество фото).
- При движении мыши над карточкой считаем `mouseX / cardWidth * N` → индекс кадра, меняем `currentFrame`.
- Активная риска синхронизирована с индексом.
- На уход мыши — возврат к первому кадру.
- На тач-устройствах hover-эффекта нет: показываем только первый кадр (карточка остаётся кликабельной для перехода в товар).

## Категории — горизонтальная лента табов

Вместо колонки слева — простая горизонтальная лента кнопок-табов сверху сетки: `Все / Леггинсы / Топы / Майки / Рашгарды / Сумки / Лонгсливы`. Активная подчёркнута тонкой линией под текстом. Сортировка — справа, как dropdown «По популярности / Цена ↑ / Цена ↓ / Новинки».

## Каждый цвет — отдельный товар

Сейчас один товар (например, рашгард) содержит 3 цвета внутри. Превращаем такие товары в **отдельные карточки** для каждого цвета, у каждой свой набор фото. На странице товара (`ProductPage`) переключателя цвета больше нет — там показываются только фото и описание выбранного варианта.

Связь между цветовыми вариантами одного товара сохраним через новое поле `colorGroup` (общий идентификатор), чтобы в будущем можно было показать «Другие цвета» на странице товара. В этой итерации — не выводим, только заводим поле.

После разделения получится примерно (от текущих ~9 товаров):
- Рашгард: 3 карточки (Чёрный, Шоколад, Айвори)
- Леггинсы компрессионные: 2 (Чёрный, Голубой) + уже отдельные Шоколад и Айвори = 4 карточки леггинсов
- Топ спортивный: 2 (Чёрный, Голубой) + Шоколад с перекрёстными бретелями = 3
- Майка моделирующая: 2 (Чёрный, Айвори)
- Сумка: 2 (Голубой, Чёрный)
- Лонгсливы: 2 (как сейчас)

Итого ~16 карточек в каталоге вместо 9.

## Технические детали

**Файлы, которые трогаем:**

1. `src/data/products.ts`
   - Добавляем поле `colorGroup?: string` в интерфейс `Product`.
   - Разбиваем мульти-цветовые товары на отдельные записи. У каждой — единственный цвет, свой набор `images` (берём из текущих `colorSpinImages[colorName]`), свой `modelUrl` (из `colorModelUrls`).
   - У каждой группы вариантов общий `colorGroup` (например, `'rashguard-zip'`, `'leggings-compression'`).
   - Уникальные `id` для новых карточек (`9-black`, `9-brown`, `9-ivory` и т. п.).

2. `src/components/ProductCard.tsx` — переписываем:
   - Убираем переключатель цветов и кнопку «В корзину».
   - Добавляем `onMouseMove` на контейнер карточки → расчёт `currentFrame` по позиции курсора; `onMouseLeave` → сброс на 0.
   - Над фото — ряд тонких рисок (`<div>` с `flex gap-1`), активная — `bg-foreground h-0.5 flex-1`, остальные — `bg-foreground/20 h-px flex-1`.
   - Подпись под фото: название (`text-xs uppercase tracking-wide`) и цена (`font-semibold`) — по центру, как на референсе.
   - Сохраняем бейджи NEW/SALE в левом верхнем углу и иконку избранного в правом верхнем (без фона-плашки, только тень для контраста).

3. `src/pages/Catalog.tsx`:
   - Удаляем `aside` с фильтрами размеров и состояние `selectedSizes`.
   - Категории становятся горизонтальной лентой табов сверху.
   - Сортировка остаётся, но превращается в один компактный `Select` справа.
   - Сетка: `grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-x-4 gap-y-10`.

4. `src/pages/ProductPage.tsx`:
   - Убираем UI выбора цвета (раз в карточке только один цвет — выбирать нечего). Оставляем выбор размера.
   - Если у товара есть `colorGroup` — в будущем можно вывести другие цвета как ссылки; в этой итерации не делаем.

5. `src/context/CartContext.tsx`:
   - Без изменений по логике, но `addItem` теперь всегда получает единственный цвет товара. Существующие корзины в `localStorage` останутся валидными.

**Что НЕ меняем:**
- SEO-разметку, breadcrumbs, sitemap (но в `sitemap.xml` позже добавим новые id товаров — отдельной правкой).
- Логику корзины, избранного, комбо-скидок.
- Страницу товара по существу — только убираем переключатель цвета.

## Ожидаемый результат

Чистая, премиальная сетка в духе planta-rosa: больше воздуха, меньше элементов управления, фокус на товарах. При наведении мыши товар «оживает» — листаются ракурсы, риски сверху подсказывают, сколько ещё кадров. Ощущение каталога становится спокойнее и дороже.
