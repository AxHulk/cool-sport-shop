

## План: заменить 3D-просмотрщик на интерактивный обзор с нескольких ракурсов

### Честная оценка
Создать качественную 3D-модель (.glb) из 2D-фотографий программно в этой среде невозможно. Для настоящей 3D-модели нужен 3D-сканер, фотограмметрия или ручное моделирование в Blender/CLO3D. Текущий GLB файл, видимо, низкого качества.

### Что предлагаю вместо этого
Сделать **интерактивный 360-обзор** из загруженных фотографий (front, angle, back) — это стандартный приём в e-commerce (Nike, ASOS, Zara используют именно его). Пользователь тянет мышью и видит товар с разных сторон.

### Реализация

1. **Сохранить 3 изображения** (`black_bra_3d_front.png`, `black_bra_3d_angle.png`, `black_bra_3d_back.png`) в `src/assets/`

2. **Создать компонент `ProductImageSpin.tsx`**:
   - Массив изображений в порядке: front → angle → back → angle(mirrored)
   - При drag/swipe по горизонтали переключает кадры
   - CSS `transform: scaleX(-1)` для зеркального angle-кадра (имитация правой стороны)
   - Плавная анимация переходов
   - Автовращение при бездействии (опционально)

3. **Обновить `ProductPage.tsx`**:
   - Для товаров с `spinImages` массивом показывать `ProductImageSpin`
   - Для товаров с `modelUrl` (GLB) оставить `ProductViewer3D`
   - Для остальных — обычное фото

4. **Обновить `products.ts`**:
   - Добавить `spinImages?: string[]` в интерфейс `Product`
   - Для товара ID 10 указать массив spin-изображений

### Альтернатива
Если вы хотите именно настоящую 3D-модель — её нужно создать в Blender или заказать у 3D-моделлера, экспортировать как `.glb` и загрузить сюда. Текущий просмотрщик GLB работает корректно, проблема в качестве самой модели.

### Технические детали
- Drag tracking через `onPointerDown/Move/Up` с расчётом deltaX
- Порог переключения кадра: ~50px горизонтального перемещения
- 4 виртуальных кадра из 3 фото (зеркалирование angle для 4-го)
- Touch-события для мобильных
- Курсор `grab`/`grabbing` для интерактивности
