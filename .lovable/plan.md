

## План: Добавить объём 3D-модели товара

Сейчас товар выглядит как плоский лист бумаги — две плоскости без толщины. Нужно придать ему объём, чтобы он выглядел как реальная вещь.

### Подход

Заменить плоские `planeGeometry` на объёмную форму — **цилиндрическую поверхность** (полуцилиндр спереди + полуцилиндр сзади). Это создаст эффект одежды на манекене: передняя и задняя текстуры будут изгибаться, как на реальном торсе.

### Что делаем

1. **Заменить плоскости на изогнутые поверхности** — использовать `CylinderGeometry` с открытыми торцами (open-ended), разделённый на две половины:
   - Передняя половина цилиндра (угол 0 → π) — текстура спереди
   - Задняя половина цилиндра (угол π → 2π) — текстура сзади
   - Радиус ~1.2, высота ~4 — пропорции торса

2. **Добавить «плечи»** — слегка расширить верхнюю часть через кастомную геометрию или масштабирование, чтобы силуэт напоминал одежду, а не просто трубу

3. **Улучшить освещение** — добавить мягкий rim-light сзади для подчёркивания объёма и формы

4. **Настроить UV-маппинг** — убедиться, что текстуры корректно ложатся на изогнутую поверхность

### Технические детали
- `CylinderGeometry(radiusTop, radiusBottom, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)` — два полуцилиндра с разными `thetaStart`
- Небольшое сужение к низу (`radiusBottom < radiusTop`) для естественного силуэта
- Добавить `pointLight` сзади для rim-эффекта
- Замедлить `autoRotateSpeed` до 1.5 для более плавного вращения
