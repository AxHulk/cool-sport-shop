

## План: Исправить 3D-модель — убрать разделение, сделать цельный объём

### Проблема
Два полуцилиндра создают видимый разрыв посередине — выглядит как два отдельных куска ткани, а не цельная вещь.

### Новый подход: «Подушка» (две выпуклые поверхности)

Вместо разрезанного цилиндра — создать две слегка изогнутые плоскости, соединённые краями:
- **Передняя поверхность** — плоскость, выгнутая вперёд (выпуклая дуга) с фронтальной текстурой
- **Задняя поверхность** — зеркально выгнутая назад с задней текстурой
- Края сходятся без зазора → силуэт напоминает торс

### Что делаем в `ProductViewer3D.tsx`

1. **Заменить `CylinderGeometry`** на кастомную геометрию из модифицированного `PlaneGeometry`:
   - Берём плоскость (напр. 2.8 × 3.6, segments 32×1)
   - Сдвигаем вершины по оси Z по синусоиде — центр выгибается вперёд на ~0.4, края остаются на Z=0
   - Для задней плоскости — зеркально (выгиб назад)
   - Результат: гладкая линзообразная форма без разрывов

2. **UV-маппинг** остаётся стандартным от PlaneGeometry — текстуры ложатся корректно без искажений

3. **Убрать импорт CylinderGeometry**, использовать `PlaneGeometry` + ручную модификацию `position` атрибута вершин

### Технические детали
- `PlaneGeometry(width, height, widthSegments, 1)` — 32 сегмента по ширине для плавной кривизны
- Для каждой вершины: `z = depth * Math.sin(u * Math.PI)` где `u` = нормализованная x-координата (0→1)
- Глубина выпуклости `depth ≈ 0.4` — достаточно для объёма, не слишком для искажения текстуры
- Задняя плоскость: `rotation-y={Math.PI}` + тот же выгиб
- Оставить текущее освещение и OrbitControls без изменений
