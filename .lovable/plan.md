

## План: Интерактивный 3D-просмотр товара

Создаём 3D-вращающийся просмотрщик товара на странице продукта. Пользователь сможет мышкой (или пальцем на мобильном) вращать товар, видя перед и зад.

### Подход
Используем **React Three Fiber** (`@react-three/fiber@^8.18` + `@react-three/drei@^9.122.0` + `three@^0.160`) — создаём плоскую 3D-плоскость (plane), на переднюю сторону которой накладывается фото спереди, на заднюю — фото сзади. Пользователь перетаскивает мышкой для вращения (OrbitControls). Выглядит как вращающаяся карточка товара в 3D-пространстве.

### Что делаем

1. **Установить зависимости**: `@react-three/fiber@^8.18`, `@react-three/drei@^9.122.0`, `three@^0.160`

2. **Скопировать изображения** в `src/assets/` как `black_jacket_front.png` и `black_jacket_back.png`

3. **Создать компонент `ProductViewer3D`** (`src/components/ProductViewer3D.tsx`):
   - Canvas из R3F с прозрачным фоном
   - Plane geometry с двумя текстурами (front/back на разных сторонах)
   - OrbitControls — только горизонтальное вращение (Y-axis), ограничение по вертикали
   - Мягкое освещение (ambientLight + directionalLight)
   - Подсказка «Перетащите для вращения»

4. **Обновить `ProductPage.tsx`**: если у товара больше 1 изображения — показывать 3D-просмотрщик вместо статичной картинки, с переключателем «3D / Фото»

5. **Добавить товар** в `products.ts` как новый рашгард с двумя изображениями (front + back), без создания новой категории

### Технические детали
- Plane с `DoubleSide` material: front-текстура на лицевой стороне, back-текстура на обратной через отдельный mesh с flipped normals
- OrbitControls: `enableZoom={false}`, `enablePan={false}`, `autoRotate` при загрузке
- Адаптивный canvas, aspect-ratio 1:1
